## Usage

Copy the desired prompt file into your AI coding agent's configuration:

- **Cursor**: `.cursor/rules/` or project root
- **Claude Code**: `CLAUDE.md` or rules directory
- **Codex**: `.copilot/prompts/`
- **OpenCode**: `.opencode/prompts/`
